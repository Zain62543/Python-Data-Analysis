# Evaluation Metrics for Regression and Classification

Explains and computes MAE, MSE, RMSE and R-squared for regression, and the main classification metrics, including visualised confusion-matrix based metrics, ROC curves and ROC AUC.

| | |
|---|---|
| **Notebook** | [`evaluation-metrics.ipynb`](evaluation-metrics.ipynb) |
| **Data** | scikit-learn `load_breast_cancer` |
| **Techniques** | Regression metrics, classification metrics, ROC / AUC |
| **Libraries** | scikit-learn, Matplotlib, Seaborn |

## Run it

```bash
# from the repository root
pip install -r requirements.txt
jupyter lab projects/classification-evaluation-metrics/evaluation-metrics.ipynb
```

- Saved outputs are from the original runs; the notebook was not re-executed after the repository was reorganised.
- Data paths are relative (`../../data/...`) so the notebook runs from its own folder.
