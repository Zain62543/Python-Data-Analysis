# Learning archive

Chronological practice notebooks from a structured data-science and AI training programme (May-August 2025), grouped by topic. The curated, better-documented work lives in [`../projects/`](../projects/).

| Folder | Notebooks | Contents |
|---|---|---|
| [`python-fundamentals/`](python-fundamentals/) | 14 | Variables and strings, tuples and dictionaries, if/elif, loops, lambda / filter / map / reduce, functions and scope, try/except, file I/O, comprehensions and generators, OOP, and two python-pptx slide-generator scripts. |
| [`pandas-and-eda/`](pandas-and-eda/) | 13 | pandas basics, a police-stops analysis, visualisation, missing-value handling with missingno and imputers, EDA on books / salaries / flights, flight-price features, and t-SNE on ANSUR body measurements. |
| [`data-collection/`](data-collection/) | 2 | REST APIs and SQL (SQLAlchemy), web scraping with requests / BeautifulSoup, and a Scrapy project with two spiders. |
| [`classical-ml/`](classical-ml/) | 20 | Entropy by hand, decision trees, PCA / t-SNE, linear and logistic regression (including from scratch), cross-validation and grid search, polynomial overfitting and bagging, random forests, K-Means and hierarchical clustering. |
| [`deep-learning/`](deep-learning/) | 8 | ANN concepts, the perceptron, Keras ANNs (housing, bank marketing, forest cover), a PyTorch salary regression, a Rock-Paper-Scissors CNN, and RNN / LSTM / GRU on IMDB reviews. |
| [`llm-apis/`](llm-apis/) | 2 | Text generation with GPT-2, GPT-J and phi-2 (Hugging Face Transformers), and chatbots on the OpenAI and Hugging Face inference APIs (keys are read from environment variables). |
